This repo is the shell

The working product — founding roll, member accounts, certification review, coins, tiers, and the members-only job board — lives in guild-server. This page is a lightweight public face that points you there.

In the Guild Hall

What members get

  • Founding roll — put your name on the charter with no dues.
  • Certifications — submit proof; CWIs and inspectors approve coins.
  • Standing — Apprentice → Journeyman → Master from verified breadth.
  • Job board — members-only postings filtered by coin tier.

Local

Run guild-server

cd guild-server
npm install
cp .env.example .env   # set ADMIN_* and SESSION_SECRET
npm start
# optional: npm run demo

Public site → http://localhost:3000
Guild Hall → http://localhost:3000/portal
Admin → http://localhost:3000/admin
